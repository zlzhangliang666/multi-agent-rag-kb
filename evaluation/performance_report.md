## 5. 局限说明

- 纯 CPU 推理（Qwen2.5-1.5B Q4_K_M），吞吐受 CPU 核数限制；
- SQLite 单文件 + 模型单进程 + 请求锁，**不适合高并发多用户**；
- `/api/agent/chat` 不逐 token 推送，无法从中测得 TTFT，真实的生成 TTFT/吞吐见第 4 节（`/api/chat/stream`）；
